# ADR-007 — Rastreabilidade externa e bidirecional

Status: aceito para o pacote inaugural.

## Decisão

Gerar mapa regra↔região real↔teste, inventário de funções/decisões e critérios públicos sem respostas; não decorar código com IDs BR.

## Razão

Toda regra deve ser testável e todo comportamento deve ter respaldo documental, sem contaminar entrada de extração.

## Consequências

IDs Joern são locais ao CPG. Spans/hashes são emitidos após implementação e revalidados após alterações; nenhuma linha fictícia no pacote inaugural.

# ADR-002 — Escopo inaugural completo e complexo

Status: aceito para o pacote inaugural.

## Decisão

Implementar todas as capacidades e regras deste pacote na primeira entrega, organizando trabalho em incrementos internos, sem cortar para poucas regras.

## Razão

A fixture é benchmark controlado para modelo robusto; reduzir artificialmente o domínio eliminaria interações necessárias ao experimento.

## Consequências

Backlog gerencia construção e risco, não redefine produto. Complexidade é comprovada por efeitos/fluxos, não por LOC ou funções numeradas por regra.

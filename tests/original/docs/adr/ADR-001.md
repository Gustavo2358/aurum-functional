# ADR-001 — Regra funcional na terminologia BRE

Status: aceito para o pacote inaugural.

## Decisão

Preservar “regra de negócio” na definição operacional O=F(I) de Huang, incluindo regras funcionais; tratar estado/configuração/tempo como entradas explícitas.

## Razão

O objetivo é alinhamento com a literatura sem restringir a avaliação a políticas comerciais. SQLite continua sendo sistema-alvo pertinente.

## Consequências

Gherkin é representação de comportamento, não a definição matemática nem evidência suficiente de equivalência. BR/FR e alcançabilidade têm escopo no avaliador.

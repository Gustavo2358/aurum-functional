# ADR-008 — Qualificação Joern não equivale a prova de slicing

Status: aceito para o pacote inaugural.

## Decisão

Separar ingestão CPG, source mapping e sentinelas de dependência da validação do extrator futuro.

## Razão

joern-slice tem critérios/limites concretos; dados não bastam automaticamente para contexto de controle eestado.

## Consequências

Não adicionar sinks falsos nem fingir completude. Gaps e NOT_RUN são visíveis, com gate J independente do funcionamento do C.

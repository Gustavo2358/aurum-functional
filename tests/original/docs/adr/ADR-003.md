# ADR-003 — C17 comum e core independente do harness

Status: aceito para o pacote inaugural.

## Decisão

Core, regras e CLI em C17 com biblioteca padrão; Python pode executar Gherkin e administrar testes.

## Razão

Precisamos de código C real para Joern e posterior comparação com SQLite, não um interpretador de regras escritas em JSON.

## Consequências

Fórmulas e decisões só no C de produção. Drivers não implementam políticas. Sem rede, banco persistente ou LLM em runtime.
